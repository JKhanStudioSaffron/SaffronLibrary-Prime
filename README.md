# SaffronLibrary Prime Pack

The Prime Pack is the core of Saffron Library: a Unity framework for building applications from small, independent systems that talk to each other through messages instead of direct references.

## What's included

- **Messaging:** commands, events, queries, requests and signals, routed between systems by domain.
- **Execution:** initialization, flow controllers, the scheduler and coroutines.
- **Infrastructure:** the application, update and input systems.
- **Presentation:** the core UI and audio systems.
- **Contracts and params:** the shared vocabulary and typed data that messages carry.
